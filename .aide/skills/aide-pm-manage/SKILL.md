# aide-pm-manage: スケジュール・課題・メンバ管理

PM として必要な管理（スケジュール／課題／体制）を作成・更新する。管理系情報は作業フォルダの管理領域（`00_pm-管理/`）に集約する。

## 手順

### 1. 管理対象の特定
ユーザーの意図から対象を判定する：スケジュール / 課題 / メンバ（体制）/ 進捗更新。複数同時でもよい。

### 2. スケジュール
- マイルストーン・WBS・依存・期限を `pm-schedule` 雛形に沿って作成/更新
- クリティカルパスと遅延リスクを明示
- 見積もりが必要なら `aide-pm-estimate` を案内

### 3. 課題管理
- 課題を `I-XXX`（連番）で起票。ステータス: OPEN→IN_PROGRESS→RESOLVED→CLOSED/WONTFIX
- High 優先度の停滞（7日以上）を警告
- 打合せ由来の未決事項は `aide-pm-meeting` から自動起票される

### 4. メンバ・体制
- 体制図・役割分担（RACI 等）・連絡先を `pm-members` 雛形に沿って整理
- リソースの過不足を指摘

### 5. レビューと反映
- 完了時に `aide-review`（`pm-reviewer`）で計画妥当性・課題追跡をレビュー
- 会話で生じた変更は `aide-sync` で反映計画→OK→反映

## 注意事項
- 見積・スケジュール・優先度・担当・ステータスは**成果物（憲章等）に含めない**。管理領域で一元管理する
- ゴール（憲章）との整合を常に確認する
