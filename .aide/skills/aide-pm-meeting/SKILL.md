# aide-pm-meeting: 議事録作成 + 課題起票

打合せメモから構造化議事録を作り、未決事項・課題・リスクを課題化する。

## 手順

### 1. 入力の取得
打合せメモ・チャットログ・文字起こしを受け取る。Office 形式は[変換ルール](../../rules.md#office-ファイル読み込みルール)でMD化してから読む。

### 2. 並列抽出
3つの観点を並列に抽出する（Claude Code ではサブエージェント並列起動、他ツールでは順次）：
- **議事録**: 日時・参加者・目的・議題ごとの論点と結論・決定事項・TODO（担当/期限）
- **課題**: 未決事項・宿題・ブロッカー
- **リスク**: 今後の懸念・依存・前提崩れ

### 3. 出力と起票
- 議事録を作業フォルダの該当フェーズの `meeting-notes`（無ければフェーズ直下）に日付付きで出力
- 課題・リスクを `00_pm-管理/` の課題管理へ `I-XXX` で起票（重複は既存に紐づけ）。議事録内に課題IDを相互参照で残す

### 4. 反映の提案
仕様・計画に影響する決定が出ていれば、`aide-sync` で該当ドキュメントへの反映計画を提示する（OK ゲート）。

## 注意事項
- 要約は中立に。決定と未決を明確に分ける
- 起票漏れを防ぐため、宿題・期限つき発言は必ず課題候補として拾う
