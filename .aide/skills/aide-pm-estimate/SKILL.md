# aide-pm-estimate: 見積もり作成

作業工数を見積もる。入力の確度に応じて精度を明示する。

## 手順

### 1. 入力確度の判定
- **通常精度（±15〜30%）**: 設計書・製造計画書があり、タスクが具体化されている
- **概算（±50〜100%）**: ラフ要件のみ。前提を多く置く

### 2. タスク分解と工数
- 作業をタスクに分解し、各タスクの工数（人日/人時）を見積もる
- 前提・含む/含まない範囲・リスクバッファを明示
- 不確実性の高い項目は範囲（最小〜最大）で示す

### 3. 出力
作業フォルダの管理領域に見積もりを出力する。精度レンジと前提を必ず併記する。

### 4. 連携
- スケジュール化は `aide-pm-manage` へ
- 設計確定後の見積変更は「計画修正」として扱い、許可なく変更しない

## 注意事項
- 精度レンジと前提条件を必ず明示する（断定的な単一値にしない）
- 見積もりは管理系情報。成果物には混ぜない
