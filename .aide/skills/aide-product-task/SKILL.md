# aide-product-task: 課題管理・設定作業記録

製品（SaaS・パッケージ）運用の課題を管理し、設定作業を記録する。

## 手順

### 1. 対象の特定
意図から判定する：課題の起票/更新 か、設定作業の記録 か。

### 2. 課題管理
- 運用課題を `00_pm-管理/` の課題管理へ `I-XXX` で起票。ステータス: OPEN→IN_PROGRESS→RESOLVED→CLOSED/WONTFIX
- 製品・バージョン・事象・優先度・対応状況を記録
- 解決には `aide-product-resolve` を連携

### 3. 設定作業記録
作業フォルダの「設定作業記録」フェーズに、再現可能な形で記録する（`product-setting-log` 雛形）：
- 対象製品・バージョン・環境（本番/検証）
- 変更前後の設定値・実施手順
- 実施日時・実施者・根拠（課題ID・参照した公式情報）
- 結果・確認方法・ロールバック手順
- 繰り返す作業は `product-procedure`（手順書）へ昇格

### 4. レビュー
完了時に `aide-review`（`product-setting-reviewer`）で妥当性・再現性・リスクをレビュー。

## 注意事項
- 設定作業記録は監査・引き継ぎの一次資料。出所と確認方法を必ず残す
- 本番変更はバックアップ・ロールバック手順を記録に含める
