# aide-product-resolve: 製品バージョン指定の問題解決

SaaS/パッケージ製品の問題を、対象バージョンに適合した公式情報に基づいて解決する。

## 手順

### 1. 製品・バージョン・事象の特定
- **製品名**と**バージョン**を必ず特定する（不明なら確認）。バージョンで挙動・設定が変わるため必須
- 事象（症状・再現条件・期待動作・実際の動作・エラーメッセージ）を整理する
- プロファイルに製品/バージョンが記録済みなら流用する

### 2. 公式情報の検索
WEB 検索で、対象バージョンに適合する一次情報を優先して収集する：
- 公式ドキュメント / リリースノート / ナレッジベース / 既知の問題（Known Issues）
- バージョン差異（対象バージョンで該当機能・設定が存在するか）を確認
- 出所（URL・ドキュメント名・対象バージョン）を必ず記録する

### 3. 解決策の提示
- 原因の仮説と、根拠（公式情報の該当箇所）を添えた解決策・設定手順を提示する
- **リスク評価**: 本番影響・不可逆操作の有無、事前バックアップ、ロールバック手段を明示する
- 複数案がある場合は影響度・確実性で比較する

### 4. レビューと適用
- 適用前に `aide-review`（`product-setting-reviewer`）でバージョン適合・リスク・再現性をレビュー
- 不可逆・本番影響のある操作は Human-in-the-Loop で承認を得てから案内する
- 実施したら `aide-product-task` で設定作業記録に残す

## 注意事項
- バージョン非適合の情報を混ぜない（出所と対象バージョンを必ず確認）
- 記憶だけで手順を断定せず、公式情報で裏を取る
- 本番環境への変更は承認・バックアップ・ロールバック手段の確認を徹底する
