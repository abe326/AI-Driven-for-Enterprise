# aide-diagram: 図の作成

成果物・ブレストの内容から `.drawio.svg` 形式の図を生成する。

## 手順

### 1. 対象と図種の特定
- 対象ファイル（成果物・ブレスト等）と図種を確認する。図種未指定なら内容から判断（フロー／構成／ER／シーケンス／ユースケース 等）
- 指定ファイルのみ読む（無関係な履歴は読まない）

### 2. .drawio.svg の生成
draw.io の XML メタデータを埋め込んだ SVG を生成する。
- draw.io で再編集可能、GitHub 上では SVG 表示
- 要素は簡潔に。色分けで視認性確保（ステータス・分類）
- 作業フォルダの該当フェーズ（無ければ対象成果物と同じ場所）に出力

### 3. 仕上げ
人間が draw.io で修正できる旨を案内する（[図の運用](../../rules.md#図の運用)：AI生成→人間修正、または人間作成→AI読み取り）。

## 注意事項
- 図は成果物の補助。正本（設計書等）の内容と矛盾させない
- 標準形式は `.drawio.svg`
