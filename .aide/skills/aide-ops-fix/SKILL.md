# aide-ops-fix: 修正対応

調査結果に基づき、既存システムを修正する。

## 手順

### 1. 前提の読み込み
T-XXX の対応記録・調査レポートを読む。修正対象の既存ソースと、関連する格納ドキュメントを読む。調査が未完了なら `aide-ops-investigate` を先に促す。

### 2. 修正方針の確認（承認ゲート）
対象ファイル・変更内容・影響範囲・副作用・テスト方法を提示し、承認を得てから着手する。本番影響・不可逆操作はロールバック手段も提示する。

### 3. 修正実装
- 既存のコード規約・パターン・アーキテクチャに沿った**最小変更**を行う
- 同種の問題が他にもあれば横展開の要否を提示
- テストを実行（または手順を提示）して回帰がないことを確認

### 4. 記録とレビュー
- 対応フォルダに修正記録（`ops-fix` 雛形）を作成：変更点・根拠（調査レポート/課題ID）・検証結果・ロールバック手順
- `aide-review`（`source-reviewer`）で既存整合・影響範囲・回帰リスクをレビュー

### 5. 次アクション
ユーザー確認後、`aide-ops-close` でクローズへ。

## 注意事項
- 既存仕様を壊さない。過剰・過小な変更を避ける
- 本番変更はバックアップ・ロールバック手順を記録に含める
