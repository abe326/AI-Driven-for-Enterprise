# aide-ops-close: クローズ・対応記録

対応完了した T-XXX をクローズし、記録を締める。

## 手順

### 1. クローズ可否の確認
T-XXX の対応記録・調査・修正記録を確認する。テスト完了・ユーザー確認が済んでいるかをチェックし、未済なら確認を促す。

### 2. 対応サマリと再発防止策
対応フォルダに最終サマリを記録する：根本原因・対応内容・解決策・検証結果・**再発防止策**（横展開・監視・手順化の要否）。障害の場合は原因分析（`ops-rca`）・再発防止策（`ops-prevention`）を整える。

### 3. ステータス更新
タスク管理（`00_pm-管理/`）の T-XXX を CLOSED（または WONTFIX）に更新し、クローズ日を記録する。

### 4. レビューと振り返り
- `aide-review`（`document-reviewer`）で記録の追跡性・完結性を点検できる
- 再発防止の学びは必要に応じ `aide-pm-retro` で振り返る

## 注意事項
- テスト・ユーザー確認なしにクローズしない
- 再発防止策は実行可能な粒度で書く（抽象的な所感で終わらせない）
