# aide-ops-investigate: 調査・原因分析

指定された対応（T-XXX）の原因と影響を調査する。**変更は行わない。**

## 手順

### 1. 対象の特定と読み込み
T-XXX の対応記録を読む。関連する格納ドキュメント（`資料-assets/`）と実ソースを読み、事象を再現・分析する。記憶で断定せず実物で確認する。

### 2. 原因調査
- 事象の再現条件を整理
- ソース・設定・ログから原因仮説を立て、根拠（ファイル:行）で裏付ける
- 影響範囲（関連箇所・副作用・回帰リスク）を特定

### 3. 調査レポート
対応フォルダ（`T-XXX-件名/`）に調査レポート（`ops-investigation` 雛形）を作成する：事象・再現・原因（根拠つき）・影響範囲・想定対応案・リスク。

### 4. レビューと次アクション
- `aide-review`（`document-reviewer` / `source-reviewer`）で調査の妥当性・影響評価を点検できる
- 修正は `aide-ops-fix` へ

## 注意事項
- このスキルでコード・設定を変更しない
- 原因は仮説と根拠を分けて記述し、未確定は未確定と明記する
