# aide-pm-retro: 振り返り（KPT）

KPT 形式で振り返りを行い、記録する。

## 手順

### 1. 過去 Try の確認
作業フォルダ内の過去の振り返り記録を読み、前回の Try が実施されたかを確認する。未実施があれば取り上げる。

### 2. KPT の収集
- **Keep**: うまくいったこと・続けること
- **Problem**: 課題・うまくいかなかったこと
- **Try**: 次に試すこと（担当・期限を付ける）

対話で引き出し、具体化する。

### 3. 記録
作業フォルダの管理領域に日付付きで振り返り記録を出力する。Try は次回確認できるよう明示する。

### 4. 連携
- Try のうち追跡すべきものは `aide-pm-manage` で `I-XXX` 起票
- プロセス改善の決定が出たら `aide-sync` で関連ドキュメントへ反映提案

## 注意事項
- 個人攻撃でなくプロセスに焦点を当てる
- Try は実行可能な粒度にする（抽象的な決意で終わらせない）
