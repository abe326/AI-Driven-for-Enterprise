# aide-ops-issue: 課題対応受付

既存運用の課題（修正対応を伴う）を受け付け、起票・管理する。

## 手順

### 1. 受付
事象・再現条件・期待動作・報告者・優先度を受け取る。**利用者が `課題-issue/` 等に先にファイルを作成して依頼した場合は、そのファイルを正として読む。** 未起票なら本手順で T-XXX を起票し、その内容を対応記録に取り込む（重複作成しない）。

### 2. 並列処理
- **類似検索**: 過去の課題対応から類似を検索
- **構造化＋T-XXX発番**
- **優先度判定**: 影響範囲・緊急度から優先度（高/中/低）を提案

### 3. 確認と起票
T-XXX・タイトル・優先度・類似を提示し承認を得る。タスク管理に起票し、`課題-issue/T-XXX-件名/` に対応記録を作成する。

### 4. 規模判断
変更ファイル多数（10超）・工数大（3人日超）・複数機能影響・アーキ変更が見込まれる場合は、新規開発フロー（`dev` セグメント）への切り替えを提案する。

### 5. 次アクション
`aide-ops-investigate` で調査へ。

## 注意事項
- 課題は `T-XXX` で追跡し、High の停滞を放置しない
- 修正は調査完了後に `aide-ops-fix` で行う（このスキルでは変更しない）
